# Conversation Actions

- `conversation.list`
- `conversation.create`
- `conversation.get`
- `conversation.delete`
- `lane.list`
- `message.list`
- `branch.list`
- `branch.create`
- `branch.switch`
- `message.append`

`message.append` 的 `message.format` 表示同一条消息正文的展示格式，当前支持 `plain`、`markdown`、`html`、`json`、`code` 和 `diagram`，缺省为 `markdown`。
